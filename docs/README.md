# VibeNavigator Documentation

This directory contains the official documentation for the VibeNavigator project.

## Directory Structure

- **getting-started/**: Guides for new users to get up and running quickly
- **api/**: API reference documentation
- **user-guides/**: Detailed guides for using various features
- **development/**: Documentation for developers contributing to the project

## File Formats

The documentation uses the following file formats:

- **Markdown (.md)**: For general documentation, guides, and READMEs
- **JSON (.json)**: For API schema documentation
- **YAML (.yaml)**: For configuration examples

## How to Use This Documentation

Reference this documentation when you need information about:
- Setting up the project
- Understanding the API
- Learning how to use specific features
- Contributing to the project

## Updating Documentation

When making changes to the project, please ensure that the relevant documentation is updated to reflect those changes.
