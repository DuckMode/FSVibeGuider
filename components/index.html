    Frontend Components¶

    Core Components¶

    Header (header.tsx)¶

    • Purpose: Main navigation header for the application
    • Features:
    • Stage progress indicator showing current workflow stage
    • Knowledge base dropdown menu
    • User profile button
    • Integration with ConceptSparkModal
    • Props:
    • totalStages: Total number of workflow stages
    • currentStage: Current active stage number
    • Notes:
    • Uses the StageProgress subcomponent to display workflow progress
    • Integrates with toast notifications for user feedback

    WorkflowSidebar (workflow-sidebar.tsx)¶

    • Purpose: Navigation sidebar showing all workflow stages
    • Features:
    • Displays all stages in the workflow
    • Highlights current active stage
    • Provides navigation between stages
    • Props:
    • stages: Array of workflow stage objects
    • currentStage: ID of the current active stage
    • Notes:
    • Uses wouter for client-side routing
    • Applies conditional styling to highlight the active stage

    MindMap (mind-map.tsx)¶

    • Purpose: Visual representation of project architecture
    • Features:
    • Displays hierarchical structure of project components
    • Supports undo/redo operations
    • Save and share functionality
    • Props:
    • title: Title of the mind map
    • data: Hierarchical data structure for the mind map
    • Notes:
    • Uses a custom color system for different node types
    • Renders a simplified visual representation of complex data structures

    ProjectProgress (project-progress.tsx)¶

    • Purpose: Visual representation of project completion status
    • Features:
    • Pie chart showing done/current/pending tasks
    • Numerical breakdown of task status
    • Current stage indicator
    • Props:
    • projectName: Name of the current project
    • stats: Object containing done/current/pending counts
    • currentStageName: Name of the current workflow stage
    • Notes:
    • Uses the PieChart component for visualization
    • Color-coded segments for different status types

    RecentActivity (recent-activity.tsx)¶

    • Purpose: Timeline of recent project activities
    • Features:
    • Chronological list of project events
    • Icon and color-coding by activity type
    • Timestamp for each activity
    • Props:
    • activities: Array of activity objects
    • Notes:
    • Each activity has an id, icon, title, description, and timestamp
    • Default activities are provided for initial state

    AIAssistant (ai-assistant.tsx)¶

    • Purpose: AI-powered assistant interface
    • Features:
    • Displays AI suggestions and recommendations
    • Accept/decline action buttons
    • Props:
    • message: The AI assistant's message
    • onAccept: Function to call when user accepts suggestion
    • onDecline: Function to call when user declines suggestion
    • Notes:
    • Uses the Bot icon from Lucide React
    • Simple interface for AI interactions

    SearchBar (search-bar.tsx)¶

    • Purpose: Global search functionality
    • Features:
    • Search across documentation, errors, and other content
    • Voice search capability
    • Props:
    • placeholder: Custom placeholder text
    • onSearch: Callback function when search is submitted
    • Notes:
    • Fixed position at the bottom of the UI
    • Includes both text and voice search options

    KnowledgeBase (knowledge-base.tsx)¶

    • Purpose: Access to documentation and learning resources
    • Features:
    • Cards for different knowledge categories
    • Integration with ConceptSparkModal
    • Props: None
    • Notes:
    • Includes cards for framework documentation, tutorials, error solutions
    • Features a special "Concept Spark" card for AI-assisted brainstorming

    ConceptSparkModal (concept-spark-modal.tsx)¶

    • Purpose: AI-assisted mind map generation
    • Features:
    • Project name and description inputs
    • AI-generated mind map visualization
    • Save functionality
    • Props:
    • open: Boolean to control modal visibility
    • onClose: Function to call when modal is closed
    • onSave: Function to call when mind map is saved
    • Notes:
    • Uses SVG for mind map visualization
    • Simulates AI generation with a loading state

    MeetSpecialists (meet-specialists.tsx)¶

    • Purpose: Introduction to AI specialists in the system
    • Features:
    • Card interface to learn about AI agents
    • Modal with detailed information
    • Props: None
    • Notes:
    • Provides information about the specialized AI agents
    • Uses a modal for detailed information display

    UI Components¶

    Button (ui/button.tsx)¶

    • Purpose: Reusable button component
    • Features:
    • Multiple variants (default, outline, ghost, etc.)
    • Size options
    • Icon support
    • Notes:
    • Built on Radix UI primitives
    • Uses class-variance-authority for variant management

    Card (ui/card.tsx)¶

    • Purpose: Container for content with consistent styling
    • Features:
    • Header, content, and footer sections
    • Title and description components
    • Notes:
    • Used extensively throughout the application
    • Provides consistent styling for content blocks

    Dialog/Modal (ui/dialog.tsx)¶

    • Purpose: Modal dialog component
    • Features:
    • Overlay background
    • Accessible dialog content
    • Header, title, description, and footer sections
    • Notes:
    • Built on Radix UI primitives
    • Used for ConceptSparkModal and other modal interfaces

    Input (ui/input.tsx)¶

    • Purpose: Text input field
    • Features:
    • Consistent styling
    • Focus states
    • Integration with forms
    • Notes:
    • Used in search bar and form inputs

    Progress (ui/progress.tsx)¶

    • Purpose: Visual progress indicator
    • Features:
    • Horizontal progress bar
    • Customizable appearance
    • Notes:
    • Built on Radix UI primitives
    • Used for loading and progress indicators

    Sidebar (ui/sidebar.tsx)¶

    • Purpose: Reusable sidebar component
    • Features:
    • Collapsible options
    • Mobile responsive behavior
    • Icon and full-width modes
    • Props:
    • side: Position of the sidebar ("left" or "right")
    • variant: Visual style ("sidebar", "floating", or "inset")
    • collapsible: Collapse behavior ("offcanvas", "icon", or "none")
    • Notes:
    • Uses context for state management
    • Adapts to mobile and desktop layouts

    Toast (ui/toast.tsx and ui/toaster.tsx)¶

    • Purpose: Notification system
    • Features:
    • Multiple variants (default, destructive)
    • Auto-dismiss functionality
    • Title and description support
    • Notes:
    • Built on Radix UI primitives
    • Used for system notifications and feedback

    Command (ui/command.tsx)¶

    • Purpose: Command palette interface
    • Features:
    • Keyboard navigation
    • Search functionality
    • Grouped commands
    • Notes:
    • Built on cmdk
    • Used for keyboard-driven navigation

    PieChart (ui/chart.tsx)¶

    • Purpose: Data visualization
    • Features:
    • Circular progress visualization
    • Multiple segment support
    • Customizable colors
    • Notes:
    • Used in ProjectProgress component
    • Uses SVG for rendering
